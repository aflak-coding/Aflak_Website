# موقع أفلاك للاستقدام

موقع ثابت (HTML/CSS/JS) بدون أي إعداد بناء.

## الهيكل
- `index.html` الصفحة
- `assets/style.css` التصميم
- `assets/app.js` السلوك (اللغة، النموذج، عرض السير، واتساب)
- `assets/cvs-data.js` **قائمة السير الذاتية**
- `assets/team-data.js` **طاقم العمل (الأسماء، المسميات، الأرقام، الصور)**
- `assets/img/team/` صور الطاقم
- `cvs/<الجنسية>/` ملفات الـ PDF
- `robots.txt`, `.nojekyll`

## إضافة سيرة ذاتية
1. ارفع الـ PDF داخل مجلد جنسيتها، مثال: `cvs/kenya/amina.pdf` (أسماء ملفات إنجليزية بدون مسافات).
2. افتح `assets/cvs-data.js` وأضف سطرًا داخل الجنسية:
   `{name:"Amina Wanjiku", ref:"K-101", job:"svc1", file:"cvs/kenya/amina.pdf"},`
   - المفاتيح: `n1` كينيا، `n2` بنغلاديش، `n3` الفلبين، `n4` إثيوبيا، `n5` سريلانكا، `n6` أوغندا
   - `job` اختياري: `svc1` عاملة منزلية، `svc2` سائق، `svc3` طباخ/طباخة
3. اعمل Commit، والموقع يتحدّث تلقائيًا.

> الأفضل إخفاء رقم الجواز والجوال من الـ PDF قبل الرفع، لأنها ملفات عامة.

## النشر على GitHub Pages
1. أنشئ Repository جديد (Public) وارفع كل محتويات هذا المجلد في الجذر.
2. Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `/ (root)`.
3. هتاخد رابط مجاني بالشكل `https://USERNAME.github.io/REPO/` وبيشتغل على طول (كل المسارات نسبية).
4. لما يبقى عندك دومين خاص بيك: Settings ← Pages ← Custom domain، واتبع توثيق GitHub الحالي لإعداد DNS، وفعّل Enforce HTTPS.
5. تحكم الكتابة: أنت فقط (صاحب الحساب). فعّل التحقق بخطوتين على حساب GitHub.

## قوقل
- Google Search Console: أضف رابط الموقع الفعلي بعد النشر. وبعد ما يبقى عندك الدومين النهائي أضف `sitemap.xml` وسطر `Sitemap:` في `robots.txt`.
- Google Business Profile: أنشئ ملف للمكتب بالعنوان والموقع وساعات العمل.

## الدومين
الموقع حاليًا غير مرتبط بأي دومين. عند اختيار دومينك أضف (1) ملف `CNAME` فيه الدومين فقط، (2) وسم `canonical` في `index.html`، (3) `sitemap.xml`.

## طاقم العمل
- عدّل `assets/team-data.js`. لإضافة صورة شخص: ضع الصورة في `assets/img/team/` واكتب مسارها في `photo:"assets/img/team/اسم-الصورة.jpg"`.
- الأرقام بالصيغة الدولية بدون `+` وبدون أصفار (السعودية `9665xxxxxxxx`، مصر `201xxxxxxxxx`).

## الخريطة
- الخريطة مضمّنة من Google Maps بإحداثيات المكتب. تعمل على الاستضافة العادية (مثل GitHub Pages).
- لتغيير الموقع: عدّل الإحداثيات داخل رابط الـ iframe في `index.html` (قسم `mapbox`).

## مهم عند الرفع
- ارفع المجلد كامل بنفس الهيكل (`assets/` و`cvs/` و`index.html` في الجذر). لو اتحط أي ملف خارج مجلده الصحيح، التصميم والصور هتختفي.

## لوحة رفع السير الذاتية للزملاء (Pages CMS - مجانية)
الموقع يقرأ السير من `data/cvs.json` ويضيف إليها أي سيرة في `assets/cvs-data.js` (الطريقة اليدوية القديمة).

### كيف تعمل الإضافة التلقائية
1. الزميل يرفع الـ PDF من قسم "رفع سيرة ذاتية - <الدولة>" في Pages CMS (يُحفظ في `cvs/<الدولة>/`).
2. GitHub Actions (`.github/workflows/process-cvs.yml`) يشغّل `scripts/process_cvs.py` تلقائيًا ويضيف الإدخال إلى `data/cvs.json`: الاسم من اسم الملف، الجنسية من المجلد، رقم مرجعي، وقص الصورة، وقراءة المهنة/الديانة/الحالة إن كانت واضحة.
3. بعد 2-5 دقائق تظهر في الموقع.
> العمر والخبرة لا يُخمَّنان آليًا (قراءة الأرقام من صورة الـ PDF غير مضمونة). تُضاف يدويًا من "السير الذاتية (تعديل البيانات)" إن أردت.

### الإعداد (مرة واحدة)
1. ادخل https://app.pagescms.org بحساب GitHub وثبّت Pages CMS على المستودع، والصق محتوى `.pages.yml` في Configuration (أو ارفع الملف للمستودع).
2. في GitHub: Settings ← Actions ← General ← Workflow permissions ← **Read and write permissions** ← Save.
3. من Pages CMS: Collaborators ← أضف بريد كل زميل.
4. ابعت لزملائك الملف `guide-for-colleagues-ar.md`.

### تجربة أولى
ارفع PDF تجريبي من قسم دولة، وانتظر، وتأكد أنه ظهر في الموقع. في GitHub تبويب **Actions** تقدر تشوف تنفيذ "Process new CVs".
